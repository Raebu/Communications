# Security

Do not disclose customer messages, identity information or provider credentials in public issues. Report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting facility if enabled; otherwise contact the owner privately before publishing details.

This is a pilot release. Production launch requires the critical gates in `docs/ROADMAP.md`. Shared provider billing, delayed usage totals, privileged operator access and provider/local transaction boundaries remain material operational risks. No secrets belong in git. Keep registration disabled until controlled onboarding is available.
